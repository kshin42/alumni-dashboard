# alumni-dashboard

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Run your tests
```
npm run test
```

### Lints and fixes files
```
npm run lint
```

## API Setup

### Golang Mod Setup
Make sure you are using golang 1.22 or above

In the top level alumni-dashboard directory run:
```
go mod tidy
```
In each api directory you can use the make commands to build:
```
make build
```
